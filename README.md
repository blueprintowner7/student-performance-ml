# Student Performance Prediction

A simple Machine Learning project that predicts a student's final score based on study hours, attendance, and previous academic performance.

## Technologies

- Python
- Pandas
- Scikit-learn
- Random Forest Regression

## Features

- Uses student performance data
- Trains a Random Forest regression model
- Evaluates the model using MAE and R²
- Predicts the final score of a new student
